## Summary

`tools/config.py set` on a field `config.toml` leaves out (a Log whose file predates the field) now places it where `tools/config.default.toml` has it, with that file's comment, instead of appending a bare line at the end.

```diff

-  regex finds the field's line → replace it
-  else → append "<field> = <value>" at the end
+  field_name() finds the field's line → replace it (as before)
+  else → placed(text, field, line)
+    a paragraph-mate in the defaults file is in the file → right beside it, no second comment
+    else, as its own paragraph under the defaults paragraph's comment:
+      after the last field that comes before it in the defaults file

```

`default_paragraphs()` reads the defaults file's layout: each field's paragraph and that paragraph's comment, which the fields sharing it (`window`/`scheduled_window`, `screen_budget`/`fit_budget`/`n`, `auto_write`/`m`) share.
