## What

One helper removes a folder git wrote in: `tools/logfiles.py`'s `rmtree(path)`. It removes git's read-only object files (Windows will not delete a read-only file) and takes a file or folder already gone as removed, with `onexc=` from Python 3.12 and `onerror=` before it. A second helper, `no_maintenance(repo)`, turns git's automatic maintenance off in a scratch repository that fetches or receives a push, so no detached `gc` is still writing there at teardown.

Every copy calls it now:

- `maintainer/devbuild.py`, `maintainer/harness.py` and `maintainer/template_checks.py` (a copy added after the issue) lose their own `rmtree` (and harness's `writable`).
