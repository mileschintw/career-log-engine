## What

One helper removes a folder git wrote in: `tools/logfiles.py`'s `rmtree(path)`. It removes git's read-only object files (Windows will not delete a read-only file) and takes a file or folder already gone as removed, with `onexc=` from Python 3.12 and `onerror=` before it. A second helper, `no_maintenance(repo)`, turns git's automatic maintenance off in a scratch repository, called right after `git init` or `git clone`: a commit, a fetch or a push it receives starts `git maintenance run --auto`, which detaches and can still be writing there (its `maintenance.lock`, a `gc`) when the test removes the folder.
